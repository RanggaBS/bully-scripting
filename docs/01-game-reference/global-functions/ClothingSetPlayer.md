# ClothingSetPlayer

## Description

Sets a specific piece of clothing to Jimmy in a specific body part.
This does not update the model visually. Call [`ClothingBuildPlayer`](https://bully-scripting.vercel.app/docs/game-reference/global-functions/ClothingBuildPlayer) for that.

```lua
function ClothingSetPlayer(bodyPart, clothing) --[[ ... ]] end
```

## Parameters

- `bodyPart`: _`integer`_ - The body part to set the clothing to.
- `clothing`: _`string`_ - The clothing to set.
